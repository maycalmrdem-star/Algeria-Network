# Algeria Network — Discord Landing Page

## Stack
- Vite + React + TypeScript
- Tailwind CSS v3
- shadcn/ui structure (`/src/components/ui`)
- Netlify deployment (`netlify.toml` + `_redirects`)

## Sections
1. **Navbar** — Logo + nav links + "Join Discord" CTA
2. **Hero** — WebGL Shader background + 3D rotating Discord orbs + headline
3. **Features** — Glassmorphism cards, 3D hover tilt
4. **Stats** — Animated counters
5. **Waitlist / Join** — Email waitlist with confetti
6. **Footer** — Links + socials
